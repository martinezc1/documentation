2  Text Analysis Project

2.1 Project Overview

The goal of this project is to build a reproducible workflow for collecting, storing, and analyzing text from online articles.

We will use:

  • Excel: as the original source of the article list.
  • R: to import, clean, scrape, and analyze the data.
  • SQLite: to store and organize the data.
  • Quarto: to document and present the final analysis.

The general workflow is:

flowchart LR
    A[Excel] --> B[R]
    B --> C[SQLite Database]
    C --> D[R: Extract Text]
    D --> E[SQLite Database]
    E --> F[R: Text Analysis]
    F --> G[Quarto Report]

The goal is to create a workflow that can be reused for future text-analysis projects.

Before getting started, please refer to ?sec-databases-sql-r

library(rvest)

url <- "https://example.com/news/article"

page <- read_html(url)

article_text <- page |>
  html_elements("p") |>

14 Key Takeaways

  • Excel can be used as the original source of article information, while SQLite can become the main working database.
  • R can connect directly to SQLite using the DBI and RSQLite packages.
  • SQLite makes it easier to store, organize, retrieve, and update article data as the project grows.
  • SQL commands can be sent to the database from R using functions such as dbGetQuery().
  • A unique article_id helps keep each article connected to its text and future analysis results.
  • Article text can be extracted in R and then written back to the SQLite database.
  • SQL is useful for filtering, counting, grouping, and retrieving data before analysis.
  • R remains the primary tool for text cleaning, tokenization, sentiment analysis, visualization, and other text-mining tasks.
  • Quarto can be used to document the entire workflow and produce the final analysis.
  • The overall workflow can be reused with future collections of articles or other documents.

16 Key Functions and Commands

16.1 Excel and Data Import

Function Purpose
read_excel() Import an Excel file into R
head() View the first rows of a dataset
str() Inspect the structure of a dataset
nrow() Count the number of rows
duplicated() Check for duplicate values
is.na() Check for missing values

16.2 Connecting R to SQLite

Function Purpose
dbConnect() Connect R to a database
SQLite() Tell R to use SQLite
dbDisconnect() Close the database connection
dbListTables() List the tables stored in the database

16.3 Reading and Writing Database Data

Function Purpose
dbWriteTable() Write an R data frame to SQLite
dbReadTable() Read an entire SQLite table into R
dbGetQuery() Send a SQL query to SQLite and return the results
dbExecute() Send a SQL command that changes the database

16.4 Basic SQL Commands

Command Purpose
SELECT Choose columns or values to retrieve
FROM Identify the table being queried
WHERE Filter records
COUNT() Count records
GROUP BY Group records before summarizing
ORDER BY Sort query results
UPDATE Change existing records
IS NULL Identify missing database values

16.5 Web Scraping

Function Purpose
read_html() Read the HTML from a webpage
html_elements() Select elements from a webpage
html_text2() Extract text from selected HTML elements

16.6 Text Analysis

Function / Package Purpose
unnest_tokens() Break text into individual words or tokens
anti_join() Remove stop words or other unwanted matches
count() Count words or other values
get_sentiments() Load a sentiment lexicon
inner_join() Match words with a sentiment lexicon
ggplot() Create visualizations
